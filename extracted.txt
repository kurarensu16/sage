1. System Overview
This document covers the full system design of the Automated Grading and Faculty Evaluation System for Dr. Yanga's Colleges, Inc. (DYCI). The system is a web-based platform that handles class record management, automated grade computation, student grade monitoring, faculty evaluation, and AI-driven academic recommendations.
The system is designed to eliminate manual grade computation, reduce the burden of grade consultations, enforce data privacy in faculty evaluations, and provide data-driven insights for both students and administration.
2. User Roles
2.1 Admin
Manage all user accounts (create, update, enable/disable)
Create and configure evaluation forms and criteria
Set evaluation window open and close dates
Perform admin override on locked posted grades
View all system data and activity logs
2.2 Dean
View all class records across departments and sections
Monitor grade posting status per faculty per grading period
View grade distribution summaries per subject and section
View AI-generated faculty fitness predictions for all faculty under their department
View the list of AI-flagged at-risk students
Generate printable and exportable summary reports
2.3 Faculty
Create class records per subject and section
Define grade components (activity, quiz, exam, project) with percentage weights
Input student scores per component
Post grades per grading period (Prelim, Midterm, Finals)
View faculty evaluation results per section (anonymized)
Receive notifications when an evaluation window closes
2.4 Student
View own grades per subject per grading period
Receive notifications when grades are posted
View personal lapses and missing score components
Submit faculty evaluations within the active window

4. Non-Functional Requirements
NFR #
Category
Requirement
NFR01
Security
Student identity in evaluations must be anonymized and non-recoverable from the UI.
NFR02
Privacy
The system must comply with Philippine Data Privacy Act (RA 10173).
NFR03
Performance
Grade computation must complete within 3 seconds of input submission.
NFR04
Usability
The interface must be usable on both desktop and mobile browsers.
NFR05
Reliability
The system must maintain 99% uptime during active evaluation windows.
NFR06
Maintainability
Codebase must follow component-based architecture for ease of updates.
NFR07
Scalability
The system must support at least 500 concurrent student users.
NFR08
Integrity
Posted grades must be immutable without an admin-logged override.
